# AI Village

Деревня, где каждый житель — отдельная LLM. Готовы шаги 1–2 из [спецификации](https://claude.ai/code/artifact/df507acc-4173-430d-9dfe-760898a4e089): детерминированный движок мира, скриптовые боты, LLM-агенты через OpenRouter и 2D-вьюер.

## Как запустить у себя (один раз настроить, дальше значок на рабочем столе)

Ничего скачивать вручную не нужно: команда ниже сама поставит всё нужное, скачает игру и положит значок «AI Village» на рабочий стол. При каждом запуске значок сам подтягивает свежую версию игры.

**Windows:** нажмите клавишу Windows, наберите `PowerShell`, нажмите Enter. Вставьте строку (правый клик мышью в окне) и нажмите Enter:

```
irm https://raw.githubusercontent.com/danel-beep/ai_village/main/scripts/install.ps1 | iex
```

**Mac:** нажмите Cmd+Пробел, наберите `Терминал` (или `Terminal`), нажмите Enter. Вставьте строку (Cmd+V) и нажмите Enter:

```
curl -fsSL https://raw.githubusercontent.com/danel-beep/ai_village/main/scripts/install.sh | sh
```

Дальше игра сама откроется в браузере, на экране «Новая деревня». Там всё настраивается ползунками и кнопками: кто живёт (ИИ-жители или бесплатные боты), сколько жителей и дней, режим экономики, насколько нечестный старт, налоги, кражи, пожары, времена года, скорость. Режим экономики сам двигает ползунки, а всё, что вы поменяли руками, отмечается зелёной точкой и запоминается до следующего раза. Ключ OpenAI или OpenRouter и модель: кнопка «⚙️ Настройки» в углу. Потом «▶ Играть». Кнопка «🔄 Новая деревня» над картой останавливает деревню и возвращает к настройкам. Прошлые прогоны и отчёт о проблеме: внизу экрана настроек. Пока играете, не закрывайте чёрное окно. Ключ и записи прогонов лежат в папке `AIVillage` в домашней папке и при обновлениях не трогаются.

Модель для ИИ-жителей по умолчанию `openai/gpt-6-luna`. Код экрана: `viewer/setup.js`, список настроек: `aivillage/knobs.py`, запуск: `aivillage/launcher.py`, скрипты: `scripts/install.*`, `scripts/start.*`.

## Запуск (для разработки)

```bash
pip install pydantic pytest
python -m aivillage.run --days 10 --bots worker,worker,thief,worker,random --log runs/demo.jsonl --fire-day 3
python -m aivillage.run --replay runs/demo.jsonl     # проверить, что лог воспроизводится один в один
python -m pytest -q
```

## LLM-агенты и 2D-вьюер

```bash
export OPENAI_API_KEY=...       # ключ OpenAI (напрямую, больше параллельных запросов)
export OPENROUTER_API_KEY=...   # или/и ключ openrouter.ai (запасной путь и модели не от OpenAI)
python -m aivillage.run --days 2 --agents 3 --models default --log runs/llm.jsonl
python -m aivillage.run --days 2 --models stub --log runs/stub.jsonl   # без ключа: «модель» отвечает как бот
python -m http.server 8000      # затем открыть http://localhost:8000/viewer/?log=/runs/llm.jsonl
```

`--models a,b,c` раздаёт модели жителям по кругу. Агенты думают параллельно, упавший провайдер = «ждать», а не падение деревни. В конце прогона печатаются вызовы, токены и стоимость по каждому агенту. Один ход стоит ~1300 токенов на вход.

### Конфиг прогона

Весь прогон можно описать одним YAML-файлом: жители, модель или бот у каждого, какие действия выключены, любые настройки мира и сценарий бога (что и когда случится). Пример с комментариями: `configs/example.yaml`.

```
python -m aivillage.run --config configs/example.yaml
```

Файл проверяется до старта: опечатка в имени поля, действия или профессии сразу даёт понятную ошибку, ни одного платного вызова модели. Флаги командной строки (`--days`, `--seed`, `--log`, `--models`, `--bots`, `--agents`) перекрывают файл. Итоговые настройки мира пишутся в шапку лога, поэтому реплею YAML не нужен.

## Живой просмотр и режим бога

```bash
pip install -e .[live]
python -m aivillage.server --days 30                                   # боты
python -m aivillage.server --agents 3 --models default   # LLM
# открыть http://localhost:8000
```

Ходы приходят в браузер сразу, пока идёт прогон. Кнопка «⚡ Режим бога» внизу справа: поджечь дом, клад, слух, засуха, болезнь, подарок, набег бандитов и зверь из леса (с предупреждением за несколько дней или внезапно), путник (может оказаться разведчиком бандитов), а также пауза и скорость (`--pace` секунд на ход). Вмешательства пишутся в лог (`runs/live.jsonl`), так что прогон по-прежнему воспроизводится через `--replay`.

## Как устроено

| Файл | Что внутри |
| --- | --- |
| `aivillage/config.py` | все числа мира: еда, цены, налог, карта, рецепты, профессии |
| `aivillage/state.py` | состояние мира (dataclasses), сериализация, хеш |
| `aivillage/registry.py` | реестр действий: из одного объявления получаются описание для промпта, JSON-схема и проверка |
| `aivillage/actions.py` | 25 действий агентов |
| `aivillage/god.py` | режим бога: пожар, клад, слух, засуха, болезнь, подарок |
| `aivillage/threats.py` | набеги, зверь, путник: угрозы извне, защита, награда; случайные шансы на стартовом экране |
| `aivillage/illness.py` | болезнь: заразна, отнимает здоровье по ночам, соседи лечат мёдом, молоком, ухой |
| `aivillage/engine.py` | `new_world`, `observe` (всё, что видит агент), `step` (один игровой час), ночь |
| `aivillage/invariants.py` | проверки после каждого хода: ничего не берётся из ниоткуда, нет отрицательных значений |
| `aivillage/bots.py` | скриптовые агенты: random (фаззер), worker (честный), thief (вор) |
| `aivillage/run.py` | прогон, JSONL-лог, реплей |
| `aivillage/runconfig.py`, `configs/example.yaml` | конфиг прогона в YAML |
| `aivillage/llm.py` | LLM-агент: промпт, разбор ответа, заметки агента, клиенты OpenAI, OpenRouter и stub |
| `viewer/index.html` | 2D-карта деревни: воспроизводит лог, мысли и реплики жителей |

Агент получает только словарь `observe(world, name)` и отвечает решением
`{"thought": "...", "action": {"name": "...", "args": {...}}, "say": "..."}`.
LLM-агенты на шаге 2 будут использовать ровно этот интерфейс, как сейчас боты.

## Как добавить механику

1. Новое действие в `actions.py` через `@ACTIONS.action(name, description, ArgsModel)`.
2. Числа — в `config.py`.
3. Тест в `tests/test_mechanics.py`. Фаззер в `tests/test_sim.py` сам начнёт вызывать новое действие.
