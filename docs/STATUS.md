## Как писать в этот файл

Этот файл правят только когда меняется план («Дальше»), решение Danel или блокер. Обычный PR его НЕ трогает: раньше каждый PR дописывал сюда строку, и почти каждое подтягивание main кончалось конфликтом в этом файле.

- Что в работе: открытые PR (`list_pull_requests`). В описании PR укажи зону файлов, которую он трогает; начав задачу, открой PR сразу после первого коммита, чтобы зону видели другие треды.
- Что сделано недавно: `git log --oneline -20 origin/main` (заголовки PR). Подробности в описании PR, `docs/specs/`, `docs/runs/`.
- PR мержится сам после зелёного CI: открыв PR, включи автомерж (`enable_pr_auto_merge`, SQUASH). Конфликт: подтяни main, разреши, запушь; автомерж сработает сам.
- Конфликт здесь у старого PR, который дописывал строку в «В работе» или «Последние изменения»: этих разделов больше нет, возьми версию main.
- Файл должен оставаться меньше 15 КБ.

## Решения Danel (не пересматривать без него)

- Цель: эксперимент, как ведут себя ИИ разных компаний. Песочница без победы. Промпт жителя нейтральный, без советов и оценок (`tests/test_neutrality.py`); конфликт рождается из правил мира, враждебность правилом не задаётся.
- Игра одна: «С нуля». Старые режимы удалены; вместо них пресеты поверх «С нуля» (`presets/*.yaml`: старт с этапа, суровые условия и т.п.). Профессий нет, роли складываются сами; больше дом = выше отдача.
- Нет природных талантов. Экономика частично дефицитная. Публичного списка долгов нет. Кража не всегда замечена; держатель казны может её тайно украсть.
- Набеги растут с оружием деревни, отбиться можно только командой. Злых жителей только по отдельной просьбе.
- Имена и места случайны, но в каждой деревне есть житель Борис.
- Все настройки в приложении (экран «Новая деревня»: «Простой» и «Расширенный»), не в терминале.
- Luna на обычном тарифе OpenAI; экономный (flex) только по отдельной просьбе.
- Ход 15 игровых минут. Бюджет игры до $5 в день. Модели для живых тестов: Luna и Haiku, 3 на 3.
