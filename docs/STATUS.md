## Последние изменения

- Лаунчер на проверенной версии: качает тег `stable` (CI ставит его только после зелёных тестов), пакеты строго из `uv.lock`, если новая версия не запустилась, запускает прошлую; старые значки на рабочем столе обновляются сами (`scripts/start.*`, `launcher.py`, PR #155).
- Лёгкий журнал: вид пишется дельтами (лог −40% на ботах), очереди сервера ограничены, живой просмотрщик держит окно ~60 дней, `logio.py`.
- Сохранность данных и денег: продолжение сохранения не теряет лог, полный учёт расходов, история = лог; `saves.py`, `server.py`, `budget.py` (PR #149).
- Тариф OpenAI по умолчанию обычный (ход ~3 с); экономный flex только если выбран в настройках (решение Danel 2026-10-08), `llm.py`/`keys.py`/`viewer/settings.js`.
- Короче подсказка жителям: правила только того, что в деревне уже открыто (на старте «С нуля» 37,5 → 23,8 тыс. знаков, PR #156), один глагол стройки `build`, факты вместо советов, `you.work_hours_left`; ручка `llm_facts`; опыт: ход на 13% дешевле, ошибок не больше (`docs/runs/prompt-short.md`).
- Дыры в правилах: заём только с согласия должника, партия у торговца стоит как поштучно, `actions.py`/`pricing.py` (PR #151).
- Честные измерения: дни без лишнего утра (частоты лаборатории были занижены на 25–33%, выводы веток не менялись), версия кода в заголовке лога, фактическая модель и задержка на каждый ход, таблица действий в `lab.md`; `social_metrics.py`, `metrics.py`, `lab.py` (PR #150).
- Ответы моделей: стандартный разбор JSON, чужая речь не выдаётся за новости, `llm.py` (PR #146).
- Честный CI: ставит `.[live,dev]` и node, Python 3.11/3.12, `pytest -n 4`; пропуск теста валит проверку (`tests/conftest.py`, PR #148).

## Решения Danel (не пересматривать без него)

- Цель: эксперимент, как ведут себя ИИ разных компаний. Песочница без победы. Промпт жителя нейтральный, без советов и оценок (`tests/test_neutrality.py`); конфликт рождается из правил мира, враждебность правилом не задаётся.

- Набеги растут с оружием деревни, отбиться можно только командой. Злых жителей только по отдельной просьбе.
- Имена и места случайны, но в каждой деревне есть житель Борис.
- Все настройки в приложении (экран «Новая деревня»: «Простой» и «Расширенный»), не в терминале.
- Luna на обычном тарифе OpenAI; экономный (flex) только по отдельной просьбе.
- Ход 15 игровых минут. Бюджет игры до $5 в день. Модели для живых тестов: Luna и Haiku, 3 на 3.
