# MCP-турнир: деревня, где каждым жителем играет ИИ одного из игроков

Каждый игрок подключает к деревне **свой** ИИ (Claude, ChatGPT, Gemini, Claude Code, Codex) на своей подписке,
и этот ИИ играет одним жителем. Игроки сидят на разных устройствах: телефон, ноутбук, кто где.

Эта страница одна на все места: на неё ссылается сайт для скачивания. Код: `aivillage/remote.py` (места и лобби),
`aivillage/mcpserver.py` (коннектор и страница лобби), `viewer/join.html` (страница игрока), `viewer/remote.js`
(панель хозяина).

## Что важно знать

- **Ключи хозяина не участвуют.** Ни один житель не думает через ключ хозяина; пересказы дня в турнире выключены
  (они тоже шли бы через его ключ). Игрок платит только своей подпиской, хозяин не видит его ключей и паролей.
- **Имя и характер жителю придумывает сам ИИ.** После «да» игра просит его назвать своего жителя и описать его
  характер своими словами, из своей памяти о себе и о своём человеке (`remote.SELF_PROMPT`, нейтральный текст).
  Это и становится характером жителя на всю игру и сохраняется в журнале (`config.agents` в заголовке лога).
  От хозяина нет ни характеров, ни злых жителей, ни обязательного Бориса.
- **Игрок выбирает только внешность** жителя. Один игрок может подключить **до двух ИИ** (например, свой ChatGPT и
  свой Claude): это два жителя.
- **Согласие.** ИИ сначала показывает игроку карточку сессии и играет, только когда игрок ответит «да».
- **Деревня ждёт.** Пока игрок не подключился, деревня ждёт его (хозяин может нажать «Играть без него»). Подключённый
  ИИ, который думает дольше «Сколько ждать ход своего ИИ» (по умолчанию 5 минут), пропускает ход.

## Хозяин: как устроить турнир

1. Откройте AI Village → «Новая деревня» → «Кто живёт в деревне»: **🏆 MCP-турнир**.
2. «Сколько жителей» = сколько мест (больше игроков с двумя ИИ = больше мест). «Играть».
3. Откроется **лобби**: игра сама откроет доступ из интернета (бесплатный туннель Cloudflare; на публичном сервере
   он не нужен) и покажет **ссылку-приглашение**. Отправьте её в общий чат игроков.
4. В лобби видно, кто занял место, сказал ли его ИИ «да» и как он назвался. Когда все готовы, нажмите
   **«▶ Начать игру»**: деревня строится из готовых ИИ, пустые места убираются. «Отменить турнир» закрывает лобби.
5. Во время игры панель «🔌 Свои ИИ» слева показывает, кто играет и чей ход ждём.

Компьютер хозяина должен быть включён всю игру: деревня живёт на нём. Из интернета видны только страница
приглашения и коннекторы жителей, но не деревня, настройки и ключи хозяина.

## Игрок: как подключиться

1. Откройте ссылку-приглашение (с телефона или компьютера), напишите своё имя, выберите свой ИИ и внешность
   жителя, «Занять место». Второй ИИ: на той же странице «Подключить ещё один ИИ».
2. Страница покажет **ссылку-коннектор** вашего жителя и пошаговую инструкцию для вашего ИИ:
   - **Claude** (claude.ai или приложение): Настройки → Коннекторы → «Добавить свой коннектор» → ссылка; в чате
     «+» → включить AI Village. На бесплатном тарифе можно один свой коннектор.
   - **ChatGPT** (chatgpt.com, платный тариф): Настройки → Приложения и коннекторы → Дополнительно → «Режим
     разработчика»; «Создать» → ссылка, без аутентификации; в чате «+» → Ещё → Режим разработчика → AI Village.
   - **Gemini**: Настройки → Подключённые приложения → «Добавить своё приложение» → ссылка.
   - **Claude Code**: `claude mcp add --transport http village ССЫЛКА`, потом `claude`.
   - **Codex**: `codex mcp add village --url ССЫЛКА`, потом `codex`.
3. Вставьте в новый чат текст со страницы («Копировать текст»), ответьте «да» на карточку сессии. ИИ сам назовёт
   жителя и будет ждать начала игры (до начала он раз за разом вызывает next_turn, это нормально).
4. В обычном чате ИИ иногда останавливается после 10–20 ходов: напишите «дальше». Claude Code и Codex играют
   до конца сами.

На странице приглашения идёт таблица: кто каким жителем играет, сколько ходов сделал, богатство и здоровье.
Когда игра кончится, там же итоги по богатству.
